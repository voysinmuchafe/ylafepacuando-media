# Y la fe pa' cuándo — media

Public delivery/archive repository for approved visual assets.

- `published/`: final approved PNG masters. These are the historical source assets.
- `transport/`: mechanically derived JPEG files used only because Instagram image publishing requires JPEG transport.
- Nothing in this repository publishes to Instagram.
- Nothing in this repository is canonical character/editorial doctrine; canon remains in the private Project repository.
- Do not store secrets, prompts, character reference sheets, rejected generations or private working files here.
